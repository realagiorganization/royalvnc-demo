# Assumptions

- No repository-level AGENTS.md exists, so only global instructions were applied.
- There is no existing automated test framework, so the BDD suite is implemented as a lightweight Python runner.
- TestFlight deployment requires App Store Connect and signing secrets that are provided in GitHub repository secrets.
- The BDD GIF in `docs/bdd.gif` is a placeholder that is regenerated by the `bdd.yml` workflow using the VHS action.
- The GitHub Pages URL is assumed to be `https://realagiorganization.github.io/royalvnc-demo/` unless overridden by `PAGES_URL` in the screenshot workflow.
